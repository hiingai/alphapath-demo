## 二、管理员账号（1 个）

| 账号 | 密码 | 说明 |
|---|---|---|
| admin1@alphapath.com | `Hkadmin123456` | 留资管理后台（登录后可看线索列表、改阶段、导出 CSV、删记录） |

管理员**不走前端账号库**，由 Worker 校验 `ADMIN_USER` / `ADMIN_PASS` 两个环境变量：

- **本机演示**（`node tools/dev_server.mjs 8123`）：默认就是 `admin1@alphapath.com` / `Hkadmin123456`，直接开
  `http://127.0.0.1:8123/admin.html` 登录。
- **线上 Pages**：目前后台是「本机演示模式」（没有部署 Worker 时用 `?demo=1` 看演示数据，不需登录）；
  真要启用登录态后台，需要部署 Worker 并设置：

```bash
npx wrangler secret put ADMIN_USER     # 输入 admin1@alphapath.com
npx wrangler secret put ADMIN_PASS     # 输入 Hkadmin123456
npx wrangler secret put ADMIN_SECRET   # 随机 32+ 字符，用于签会话
npx wrangler deploy
```

> ⚠️ 生产环境不要用这组测试密码；`ADMIN_PASS` 换成强密码，`ADMIN_SECRET` 用随机值。

## 三、自检命令

```bash
node tools/seed_accounts.mjs --check    # 用明文重新派生，确认 10 个账号摘要都匹配
node tools/probe_seed.mjs 9241          # 浏览器端到端：导入 → 登录 → 错密码被拒 → 后台登录
```

## 四、想重新生成一批账号

```bash
node tools/seed_accounts.mjs            # 重新生成随机盐，覆盖 accounts.seed.json
```

改密码/改数量：编辑 `tools/seed_accounts.mjs` 顶部的 `USERS` / `ADMINS` 常量后重跑，再执行 `--check`。
